# Segurança

Não publique tokens, chaves API, imagens de propriedades, bancos, backups ou dados de operadores em issues ou pull requests.

Para relatar uma vulnerabilidade, abra um aviso privado no GitHub ou contate o mantenedor antes de divulgar detalhes. Inclua versão, passos mínimos reproduzíveis com dados sintéticos, impacto e uma sugestão de correção quando possível.

O MVP não foi auditado para SaaS público. Em produção, use TLS, gateway de identidade, secret store, controle de rede, logs sem conteúdo sensível e backups testados.
